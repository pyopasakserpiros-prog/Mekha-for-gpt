# MeKha 2.1.0 — กิจการสำนักและชีวิตโลก

แตก ZIP แล้วเปิด **index.html** ด้วย Chrome เล่นออฟไลน์ได้ ไม่ต้องติดตั้งโปรแกรม เปิดเซิร์ฟเวอร์ หรือดาวน์โหลดโมเดล

ต่อจาก 2.0.0 ที่แนบมาโดยตรง ข้อมูลไอเทม วิชา เรื่องราว และระบบเดิมยังอยู่ครบ
ส่งออกเซฟรุ่นเดิมเก็บไว้ก่อน จากนั้นนำเข้าในเมนูบันทึก/นำเข้าของรุ่นใหม่ได้ เซฟใหม่เป็น schema 8 จึงนำกลับไปเปิดในรุ่นเก่าไม่ได้
ตำแหน่งไฟล์ HTML ใหม่อาจไม่เห็นเซฟในเบราว์เซอร์ของตำแหน่งเก่า ให้ใช้ไฟล์ส่งออก/นำเข้า

จากหน้าแรก เปิด **ข้อร้องเรียน / อำนาจ / การค้า / ข้อมูลฝึก** เพื่อบริหารข้อร้องเรียน ดูฐานสนับสนุน ขบวนค้า และเปิดหรือปิดการเก็บผลสำหรับฝึก AI
เปิด **ทะเบียนกิจกรรมทั้งหมด** เพื่ออ่านกิจกรรมตามหมวด และ **เปิดโลกจำลอง** เพื่อดูแผนชีวิต ข่าว ความทรงจำ และพงศาวดาร

- ทะเบียนเดิม 220 คำมีระบบรองรับครบ เพิ่มอีก 16 รายการ รวม 236 รายการ
- 212 รายการเป็นกิจกรรมที่มีตัวตรวจเงื่อนไขและตัวดำเนินการร่วม อีก 24 รายการใช้ระบบเดิม งานประจำ หรือเป็นผลเหตุการณ์
- สมาชิกเราและบุคคลในสำนักอื่นใช้ส่วนร่วมเดียวกัน แต่สิทธิ์ หน้าที่ บุคลิก ข่าวที่รู้ และนโยบายทำให้ทางเลือกต่างกัน
- กู้เงินมีผู้จ่ายและกำหนดคืน ผลิตของและเรียนวิชาต้องใช้เวลา การค้ามีสินค้าและเงินค้ำจริง การรบใช้กำลังและมีบาดเจ็บ
- การเมืองภายในมีข้อร้องเรียน กลุ่มสนับสนุน การตรวจสอบ ลงมติ ชิงอำนาจ และสละตำแหน่งตามเงื่อนไข
- เซฟในเบราว์เซอร์บีบอัดแบบไม่สูญเสียข้อมูล ส่วนไฟล์ส่งออกยังเป็น JSON ปกติ หากพื้นที่เต็มให้ส่งออกไฟล์เซฟ

**ข้อมูลฝึก:** ปิดไว้เป็นค่าเริ่มต้น เปิดเก็บได้เอง สุ่มทุก 20 การตัดสินใจ เก็บสถานการณ์ก่อนเลือก ทางเลือกที่ตรวจแล้ว และผลหลัง 30/90/180 วัน จำกัด 128 รายการรอติดตามและ 256 รายการครบระยะ ส่งออกผ่านปุ่มในเกม
ยังไม่ได้ฝึกหรือเชื่อม AI Ranker / SectWorld Brain ในแพทนี้ ข้อมูลการเล่นอย่างเดียวไม่พิสูจน์ว่าทางเลือกที่ไม่ได้เลือกแย่กว่า ต้องจำลองทางเลือกเปรียบเทียบในขั้นฝึกต่อไป
