# เมฆา 1.3.0 — ชีวิตสำนักและคัมภีร์ที่จับต้องได้

เปิด `index.html` ด้วย Chrome ได้โดยไม่ต้องเชื่อมต่ออินเทอร์เน็ต ไม่ต้องติดตั้งโปรแกรมหรือแก้โค้ด หน้าเกมเป็นภาษาไทย

## การใช้เซฟเดิม

ส่งออกเซฟจากเกมเก่าก่อน เปิด index.html ของ 1.3.0 แล้วนำเข้าเซฟผ่านเมนูบันทึก รองรับเซฟเมฆาเดิมรูปแบบ 1, 2 และ 3 การแปลงไม่แจกทรัพยากรเพิ่ม ไม่เปลี่ยนคน ไม่สุ่มใหม่ และรักษาวิชาที่สำนักค้นพบไว้แล้ว นโยบายเดิมยังอยู่ การจำลองกิจกรรมส่วนตัวเปิดเพิ่มให้ หากต้องการให้ผู้บริหารจัดงานหลักด้วย ให้ใช้ปุ่มมอบงานประจำในหน้าบริหาร

## คัมภีร์และสิทธิ์เรียน

มีคัมภีร์จริง 138 ชนิด: วิชาใช้งาน 114 และคัมภีร์บ่มเพาะ 24 รวมไอเทมทั้งเกม 800 ชนิด ของเดิม 662 ชนิดยังอยู่ครบ

เกมใหม่เริ่มด้วยวิชาพื้นฐานของสำนัก 12 วิชา หน้า “หอวิชา” แสดงเฉพาะตำรับที่สำนักมีแล้ว วิชาที่ยังไม่พบซ่อนจากรายชื่อเรียน คัมภีร์ที่ได้จากการสำรวจ เรื่องราว การจารึกของผู้รู้ หรือ Edit อยู่ในคลัง ไม่เปิดสอนทันที

เปิดคลัง เลือกหมวดคัมภีร์ เลือกม้วน แล้วกด “ใช้ → ตั้งสิทธิ์และคัดลอก” จ่ายคัมภีร์หนึ่งม้วน เงิน และไม้ จากนั้นสมาชิกแบ่งเวลาทำงานคัดลอก เมื่อแรงงานครบจึงเปิดสอน คิวมีได้สามงาน ยกเลิกคืนม้วน แต่ไม่คืนวัสดุเตรียมงาน คัมภีร์ซ้ำเก็บ ล็อก หรือขายได้

สิทธิ์เลือกตำแหน่งใดบ้างที่เรียนได้ และอนุญาตรายคนเพิ่มเติมได้ ทั้งวิชาใช้งานและคัมภีร์บ่มเพาะ ผู้เรียนยังต้องผ่านเงื่อนไขมรรคา ขอบเขต ฐานรากและความสามารถ การเรียนอัตโนมัติก็ตรวจสิทธิ์ ถ้าถอดสิทธิ์ระหว่างเรียนจะพักความคืบหน้า การถอดสิทธิ์ไม่ลบความรู้ที่ตัวละครเรียนสำเร็จไปแล้ว

ผู้รู้วิชาสามารถจารึกเมื่อชำนาญอย่างน้อย 60% ใช้เงินและไม้ จากนั้นสะสมเวลาเป็นม้วนเข้าคลัง ผู้เล่นจึงตัดสินใจว่าจะคัดเข้าหอหรือขาย วิชาประจำตัวของผู้เดินทางไม่ได้เผยแพร่ให้ทุกคนอัตโนมัติ

## ชีวิตตอนข้ามเวลา

สมาชิกประเมินกิจกรรมรองทุกวันจากสุขภาพ ความเหนื่อย ภาระกาย ฐานราก อุปกรณ์ วิชาที่จัดใช้ สิทธิ์หอวิชา บุคลิก ความชอบ หน้าที่ ความสัมพันธ์ และทรัพยากรจริง พร้อมแผนต่อเนื่อง เช่นเตรียมทะลวง สะสมผลงานช่าง ช่วยชุมชน หรือรักษาชีวิตสงบ

เพิ่มกิจกรรม 18 แบบ: พักฟื้น ทบทวนฐานราก อ่านตำรับ ฝึกวิชา ปรึกษาผู้รู้ พบสหาย ชี้แนะศิษย์ ประลอง ดูแลอุปกรณ์ ช่วยเสบียง เยี่ยมชุมชน ทดลองช่าง คัดคัมภีร์ ประชุมฝ่าย ไกล่เกลี่ย ปรับความเข้าใจ วางแผนเรียน และพักชมทิวทัศน์

งานหลักใช้ประมาณ 82% ของเวลาเมื่อมีแผนกิจกรรมรอง อีก 18% ให้กิจกรรมรอง มีผลต่อแรงงาน/การฝึกจริง ผู้ที่เรียนวิชาเต็มวันหรือทำเรื่องราวไม่ทำกิจกรรมรองซ้อน การพบปะหรือประลองใช้ช่องกิจกรรมของทั้งสองคน วันหนึ่งคนหนึ่งทำกิจกรรมรองได้หนึ่งครั้ง การเลือกกิจกรรมมีช่วงเว้นและลดน้ำหนักกิจกรรมที่เพิ่งทำ

ตัวอย่างผลจริง: การคุยเปลี่ยนความสัมพันธ์และความพอใจ การช่วยศิษย์เพิ่มฐานรากของผู้รับคำแนะนำ การประลองเพิ่มประสบการณ์และความล้า การทดลองช่างใช้แร่ 0.5 การดูแลอุปกรณ์ใช้แร่ 0.3 การคัดตำรับสะสมแรงงาน การอ่านเลือกเฉพาะตำรับที่มีสิทธิ์ การใช้โอสถหรือได้รับอุปกรณ์ทำให้ประเมินแผนส่วนตัวใหม่

หน้า “ชีวิตสมาชิก” และรายละเอียดตัวละครแสดงกิจกรรม วัน เหตุผล ผู้เกี่ยวข้อง และผลเปลี่ยนจริง เก็บกิจกรรมล่าสุด 96 รายการ สรุปกิจกรรมรายเดือน 24 เดือน แยกจากสรุปงานหลักเดิม ลดข้อความรายสัปดาห์ที่วนบอกงานเดิม

## ผลจากนโยบายและเงิน/ของที่เพิ่ม

ผู้บริหารตรวจนโยบายที่เปลี่ยนและประเมินการลงทุนทุกสามวัน เลือกงานที่จ่ายได้โดยรักษาสำรอง มีข้อจำกัดจำนวนอนุมัติตามความสามารถบริหาร เช่น เงินที่ผู้เล่นเพิ่มอาจเปิดโอกาสสร้างอาคาร ผลิตอุปกรณ์ที่ขาด ซื้ออาหาร หรือผลิตโอสถตามผู้ใช้จริง ไม่ใช่เพิ่มเงินแล้วอาคารเกิดฟรี

การแจกของเดิมยังทำทุกวันและเมื่อเสก/ซื้อเข้าคลัง เลือกของที่เหมาะกับหน้าที่และวิชา ของที่เกินเกณฑ์หรือใช้ไม่ได้ยังอยู่ในคลัง ไม่เปลี่ยนของล็อก ไม่ย้ายของที่คนอื่นใส่ ไม่ข้ามช่วงเว้นยา และรักษางบมูลค่าแจกต่อวัน

เพิ่มตัวเลือกส่งสำรวจอัตโนมัติและขายคัมภีร์ซ้ำอัตโนมัติ ทั้งสองปิดไว้เริ่มต้น ผู้เล่นเปิดได้ในหน้าบริหาร การขายคัมภีร์ซ้ำรักษาฉบับสำรองอย่างน้อยหนึ่งม้วน และไม่ขายม้วนที่ยังไม่คัดลอก การสำรวจเลือกทีมพร้อมและไม่ดึงคนที่ล็อก งานผลิต/ก่อสร้าง/เสบียง หรือผู้บริหารออกไป

ผู้บริหารประเมินอาหารตามฤดูกาลและการบริโภคจริง รายได้เทียบค่าบำรุงและเบี้ยเลี้ยง เลือกผู้ทำงานจากความถนัด เติมแรงงานจำเป็นก่อน แล้วกันกำลังไว้ฝึกระยะยาว การลงทุนอัตโนมัติเก็บเงินค่าบำรุงอย่างน้อย 14 วัน เพิ่มค่ายป้องกันและโรงหลอมเมื่อจำเป็น การเรียนอัตโนมัติไม่ดึงคนจากงานอาหาร รายได้ ล่า ยาม ก่อสร้าง หรือผลิต และยังเคารพงานที่ผู้เล่นล็อก

## ตำแหน่งและโลกภายนอก

เพิ่มผู้คุมกฎ ทูตซ้าย ทูตขวา และผู้อาวุโสฝ่ายกิจการนอกสำนัก ตำแหน่งละหนึ่งคน ใช้การแต่งตั้งผู้อาวุโสและตำแหน่งไม่ซ้ำคนตามกฎเดิม

ผู้คุมกฎไกล่เกลี่ยข้อขัดแย้ง ผู้เที่ยงธรรมกับผู้ลำเอียงมีผลต่างกัน ทูตซ้ายช่วยประสานภายใน ฝ่ายภายนอก/ทูตขวาช่วยข่าวและไมตรีเมื่ออนุญาตการทูต ใช้เงินส่งหนังสือจริง รองเจ้าสำนักหรือทูตซ้ายรักษาการเมื่อเจ้าสำนักไม่พร้อม ช่วงเปลี่ยนผู้นำ 20 วันลดผลบริหารงานและการเรียนเป็น 80%

คนต่างสำนักมีการพัก พบเพื่อน ปรึกษา ทบทวนฐานราก ช่วยเสบียง ผู้นำพิจารณาไมตรีหรือเตรียมกำลังตามความสัมพันธ์กับผู้เล่น ใช้ทุน/อาหารของฝ่ายจริง กิจกรรมรองหักเวลาฝึกส่วนหนึ่ง ข่าวที่ผู้เล่นเห็นเป็นภาพ ณ วันที่รับข่าว ไม่เปิดข้อมูลสดทั้งหมดผ่านการเปิดหน้า

โลกยังเดินเมื่อผู้เล่นเดินเวลาในเกม หยุดเมื่อปิดเกม และยังหยุดตามเหตุสำคัญ/คำถามที่กำหนด ไม่รับประกันว่าสำนักจะสำเร็จหรืออยู่รอดทุกโลก

## Edit และการใช้งานมือถือ

แก้ช่องจำนวนเสกที่ถูกการวาดหน้าซ้ำแย่งโฟกัส ใช้ช่องตัวเลขมือถือและปุ่ม 1 / 10 / 100 / 1,000 เลือกจำนวนแล้วเสกได้จริง เพิ่มหมวดคัมภีร์และปุ่มเสกคัมภีร์ทั้งหมดเข้าคลัง ปุ่มนี้ไม่ได้เปิดสอนทุกวิชา

Edit ตัวละครมีฉบับร่าง เลือก Traits หลายอันแล้วตกลงครั้งเดียว แบ่งหมวด ค้นชื่อ/ผล เลือกมรรคาและชื่อขอบเขต ปรับความก้าวหน้า ชื่อ อายุ ค่าสถานะ บุคลิก พรสวรรค์ สุขภาพและอาการต่าง ๆ มีตกลง/ยกเลิก เปลี่ยนมรรคาแล้วถอดชุดวิชา/อุปกรณ์ที่ใช้ไม่ได้ กายาพิเศษเลือกได้หนึ่งชนิด

ทุกหน้ารายละเอียดมีแถบ “✕ ปิด” ด้านบน และมีปุ่มย้อนกลับเมื่อเปิดซ้อนกัน ปุ่มบันทึกฉบับร่างอยู่ท้ายหน้าที่ติดขอบเมื่อเลื่อน

## ขอบเขตการตรวจสอบ

ทดสอบด้วยเอนจินจริง การกดคำสั่งและเรนเดอร์ UI ผ่านตัวจำลอง DOM ตรวจไฟล์ index.html แบบรวมและการทำงานเมื่อ localStorage ถูกปิด ทดสอบโลกหลายปีและการต่อเซฟ ค่าการประเมินเป็นจำนวนทางเลือกที่ตรวจ ไม่ใช่จำนวนคำสั่ง CPU

สภาพแวดล้อมนี้ไม่มีเบราว์เซอร์ Chromium ที่รันได้ และการดาวน์โหลดถูกปฏิเสธ จึงยังไม่ได้ทดสอบการสัมผัส/คีย์บอร์ดบน Android จริง หรือวัดความเร็วบน Snapdragon 8 Elite การจำลองแบ่งการเดินเวลาเป็นช่วงเพื่อให้หน้าเกมตอบสนองได้
