# ตำนานสำนักเมฆาสงบ — คู่มือผู้เล่น (Android + Chrome)

## 1) แตกไฟล์และเปิดเกม
1. ดาวน์โหลดไฟล์ ZIP ลงโทรศัพท์ (ปกติอยู่ในโฟลเดอร์ ดาวน์โหลด)
2. เปิดแอป **ไฟล์ (Files)** ของ Google หรือแอปจัดการไฟล์ของเครื่อง → แตะไฟล์ ZIP → เลือก **แตกไฟล์ (Extract)** แตกเป็นโฟลเดอร์ใหม่ (ต้องแตกทั้งหมดก่อน ห้ามเปิดจากในไฟล์ ZIP)
3. เข้าโฟลเดอร์ที่แตกแล้ว แตะ `index.html` → เลือกเปิดด้วย **Chrome**
   - ถ้าเครื่องเปิดด้วยแอปอื่น ให้เปิด Chrome แล้วพิมพ์ในแถบที่อยู่ `file:///storage/emulated/0/Download/` แล้วเข้าโฟลเดอร์ที่แตกไว้ แตะ `index.html` (ชื่อโฟลเดอร์อาจต่างกันตามที่คุณแตกไฟล์)
4. เกมทำงานออฟไลน์ทั้งหมด ไม่ต้องต่ออินเทอร์เน็ต
5. เพื่อความสะดวก ใน Chrome เลือกเมนู ⋮ → **เพิ่มลงในหน้าจอหลัก** ได้ (อาจใช้ได้หรือไม่ได้กับลิงก์แบบไฟล์ ขึ้นกับเวอร์ชัน Chrome)

> ข้อควรระวัง: เซฟอัตโนมัติเก็บในที่เก็บข้อมูลของ Chrome ของ "ที่อยู่ไฟล์นี้" ถ้าคุณย้ายโฟลเดอร์เกม หรือล้างข้อมูลเว็บไซต์ของ Chrome เซฟในเบราว์เซอร์อาจหาย จึงควร **ส่งออกเซฟเป็นไฟล์** เก็บไว้เป็นระยะ

## 2) ส่งออก / นำเข้าเซฟ
- เมนู → บันทึก → **ส่งออกเป็นไฟล์ .json** ไฟล์ชื่อ `sect-save-dayXXX.json` จะอยู่ในโฟลเดอร์ ดาวน์โหลด
- ถ้าดาวน์โหลดไม่ได้ ใช้ **คัดลอกข้อความเซฟ** แล้ววางลงบันทึก/แชตของคุณเอง
- นำเข้า: เมนู → บันทึก → เลือกไฟล์ `.json` หรือวางข้อความ → **นำเข้า** (แทนที่เกมปัจจุบัน) เกมจะตรวจสอบไฟล์ก่อน ถ้าไฟล์เสียหายหรือถูกแก้ จะปฏิเสธพร้อมบอกเหตุผล
- มีช่องเซฟ 3 ช่อง + เซฟอัตโนมัติ (ทุกประมาณ 7 วันที่เดินเวลา) + สำรองอัตโนมัติก่อนหน้า 1 ชุด

## 3) การเล่นเบื้องต้น
- **แถบล่างสุดเหนือแท็บ:** กด +1, +7, +30, +90 วัน หรือ "▶ ถึงเหตุสำคัญ" ระหว่างจำลองมีแถบความคืบหน้าและปุ่ม **หยุด**
- เกมหยุดเองเมื่อเกิดเหตุที่คุณตั้งไว้ (เมนู → การหยุดอัตโนมัติ) หรือมีเรื่องต้องตัดสินใจ (การ์ดสีทองในหน้าภาพรวม)
- **ภาพรวม:** เรื่องรอตัดสินใจ สถานะ คลังและรายได้ต่อวัน (แตะแต่ละทรัพยากรเพื่อดูว่ามาจากอะไร) เหตุการณ์สำคัญ
- **ศิษย์:** กรองตามยศ/สาย/งาน/บาดเจ็บ/พร้อมทะลวง ค้นชื่อ เรียงลำดับ โหมด "เลือกหลายคน" เพื่อตั้งงานทีละมาก ๆ แตะชื่อเพื่อดูรายละเอียด ทะลวงขั้น เปลี่ยนคัมภีร์/สาย ตั้งงาน เลื่อนยศ รางวัล ลงโทษ อาจารย์
- **สำนัก:** คลัง/ตลาด อาคาร ปรุงยา/หลอมอาวุธ นโยบาย คัมภีร์ ผู้สมัคร
- **โลก:** ฝ่ายต่าง ๆ และการทูต ชุมชนศรัทธา คณะสำรวจ บันทึกการสู้รบ
- **รายงาน:** บันทึกเหตุการณ์ กรองตามหมวด กด "เหตุผล/รายละเอียด" เพื่อดูสาเหตุ
- ปุ่มย้อนกลับของ Android ปิดหน้าต่างรายละเอียดที่เปิดอยู่

## 4) คำแนะนำช่วงแรก
1. ให้ระบบมอบหมายงานอัตโนมัติไปก่อน แล้วเดิน +7 วัน อ่านรายงาน
2. ดูว่า **เสบียง** และ **เงิน** ติดลบหรือไม่ (ตัวเลขสีแดงในภาพรวม) อย่าให้ศิษย์อดอยาก
3. รับศิษย์ใหม่ในหน้า สำนัก → ผู้สมัคร ตามที่พักและเสบียงที่มี
4. สร้าง "สวนสมุนไพร", "ค่ายป้องกัน/กำแพง" และอื่น ๆ เมื่อมีทรัพยากร
5. ศิษย์สายศรัทธาควรได้ดูแลชุมชน ดูหน้า โลก → ชุมชนศรัทธา เพื่อแก้ความต้องการเร่งด่วนก่อนหมดเวลา
6. ก่อนปล่อยเดินเวลานาน ๆ ให้ตรวจนโยบายป้องกันและเสบียงสำรอง

## 5) ถ้าเกมมีปัญหา
- หน้าจอว่าง: ตรวจว่าแตกไฟล์ ZIP ครบ และเปิด `index.html` จากโฟลเดอร์ที่แตกแล้ว (ต้องมีโฟลเดอร์ `js` และ `css` อยู่ข้าง ๆ)
- เซฟอัตโนมัติไม่ติด: ส่งออกเป็นไฟล์แทน (บางโหมดความเป็นส่วนตัวบล็อกการเก็บข้อมูล)
- พบข้อผิดพลาดซ้ำ ๆ: ส่งออกเซฟ แล้วเริ่มเกมใหม่/นำเข้าอีกครั้ง
