# ผลตรวจเมฆา 1.3.0

ตรวจซอร์สและไฟล์เล่นแบบรวมด้วย Node.js ในสภาพแวดล้อมทดสอบนี้ ไม่ใช่การวัดความเร็วบนโทรศัพท์

## การทำงาน

ผ่านการทดสอบเอนจิน 91 กลุ่ม: ระบบเดิม 26, แพตช์พื้นฐาน 19, การบริหารและโลก 17, ชีวิต/คัมภีร์/สิทธิ์/เซฟ 25 และการพยากรณ์งาน 4

ตรวจคัมภีร์ครบทุกวิชา การค้นพบไม่เปิดสอนทันที การคัดลอกและจารึกใช้ของ/แรงงานจริง สิทธิ์รายยศและรายคน การพักเรียนเมื่อถอดสิทธิ์ เวลาที่ใช้กิจกรรมคู่ไม่เกินหนึ่งกิจกรรมรองต่อคนต่อวัน ผลต่อค่าและการใช้วัสดุจริง ผู้นำรักษาการ ตำแหน่งใหม่ และร่างแก้ตัวละครที่ไม่เปลี่ยนข้อมูลจนตกลง

ตรวจแปลงเซฟเดิมและนำเข้าเซฟที่เก่ากว่าวันปัจจุบัน ตรวจเดินรายวันเทียบการข้ามเวลาเป็นช่วงและโหลดเซฟแล้วเดินต่อ ได้การตัดสินใจ/เหตุการณ์ตรงกัน ตรวจข้อมูลไม่ถูกต้องถูกปฏิเสธก่อนกระทบเกม

## หน้าจอและไฟล์เล่น

UI เดิมและหน้าบริหารผ่านการเรนเดอร์ด้วย DOM จำลอง หมวดเสกเข้าถึงไอเทม 800 ชนิด UI ใหม่ผ่าน 213 การเรนเดอร์และ 5 กระบวนการกด: ช่องจำนวนไม่วาดใหม่ขณะพิมพ์, แก้ตัวละครตกลง/ยกเลิก, สิทธิ์หอวิชา, คัดลอก และปิด/กลับหน้ารายละเอียด

ไฟล์ index.html ไม่มีสคริปต์หรือ CSS ภายนอก ตรวจการเริ่มเกม กดปุ่ม เดินเวลา และส่งออกเซฟจากโค้ด inline จริง ทั้งกรณี localStorage ใช้งานได้และถูกปิด

ไม่มี Chromium ที่ใช้งานได้ในสภาพแวดล้อมนี้ จึงยังไม่ได้ตรวจการสัมผัส แป้นตัวเลข หรือความเร็วบน Android/Snapdragon 8 Elite จริง

## การจำลองระยะยาว

6 โลก โลกละ 3,600 วัน รวม 21,600 วัน มีการเพิ่มทรัพยากรวัน 180 และเปลี่ยนนโยบายวัน 540/1080/1800 ตามที่ระบุใน tests/living-longrun.js ตรวจเซฟระหว่างทาง ค่าจำกัด และทรัพยากรไม่ติดลบ ผลรายละเอียดอยู่ใน tests/results-v130-longrun.json

อีก 2 โลก โลกละ 7,200 วัน รวม 14,400 วัน ไม่เพิ่มทรัพยากรและไม่บังคับเปลี่ยนนโยบาย ใช้การบริหารเริ่มต้น ตอบคำถามค้างด้วยตัวเลือกเริ่มต้น ทั้งสองโลกมีสมาชิก 18 คนเมื่อครบ 20 ปี อาหารคงเหลือ 471/464 และเงิน 519/513 ตามลำดับ ผลอยู่ใน tests/results-v130-natural.json

การทดสอบสมดุลรอบแรกพบผู้บริหารจัดงานผลิตมากเกินไป รายได้ไม่ครอบคลุมและฝึกน้อย จึงแก้การจัดงานเป็นการพยากรณ์อาหารตามฤดูกาล รายได้เทียบค่าบำรุง เลือกคนตามความถนัด กันคนฝึก เก็บเงินค่าใช้จ่าย 14 วัน และเพิ่มแผนค่ายป้องกัน จากนั้นทดสอบชุดข้างต้นใหม่

การผ่านในเมล็ดสุ่มเหล่านี้ไม่รับประกันการอยู่รอดทุกโลก ผู้เล่นอาจเปลี่ยนนโยบายหรือการกระทำให้ผลต่างออกไป จำนวนการประเมินในผลทดสอบหมายถึงจำนวนทางเลือกกิจกรรมที่ตรวจ ไม่ใช่คำสั่ง CPU
