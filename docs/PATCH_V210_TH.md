## กิจกรรมและผลที่เชื่อมครบ

ตรวจทะเบียนเดิม 220 รายการ ไม่มีรายการ supported=false เหลือ เพิ่ม 16 รายการ รวม 236
กิจกรรมตามเงื่อนไข 212 รายการมี choose/check/run/priority และตรวจซ้ำก่อนดำเนินการ อีก 24 รายการอยู่ในระบบเดิม/งานประจำ/เหตุการณ์ ไม่ควรป้อนเป็น 236 ทางเลือกอิสระให้โมเดล

| หมวด | ผลจริงหลัก |
|---|---|
| บ่มเพาะและวรยุทธ์ | ใช้ทรัพยากร เพิ่มความก้าวหน้า/ฐานราก/ความชำนาญ เรียนและสร้างแขนงใช้เวลา |
| สุขภาพ | ลดบาดเจ็บ พิษ หรือความเหนื่อย จ่ายสมุนไพรหรือใช้โอสถจากของที่ถือ |
| ความสัมพันธ์และข่าว | ความไว้ใจ บุญคุณ คู่ปรับ ข่าวมีต้นทาง ปกปิดข่าวหยุดการส่งต่อผ่านวงสนทนา |
| ชีวิตประจำวัน | กิน นอน พัก งานอดิเรก ดูแลที่พัก สร้างครอบครัวเมื่อผู้ใหญ่ทั้งสองสมัครใจ |
| เศรษฐกิจ | เงินส่วนตัว โอนเงินกู้ คืนหนี้รวมกรณีเลยกำหนด ผลิตหลังใช้แรงงาน ของมีเจ้าของ |
| การค้าและการเดินทาง | จ่ายเสบียง ใช้เวลาเดินทาง ขบวนสินค้าและเงินค้ำอาจส่งถึง ถูกปล้น หรือคืนเมื่อฝ่ายล่ม |
| กิจการสำนัก | รับคน เลื่อน/ลดตำแหน่ง จัดของและยา ภารกิจ ก่อสร้าง ซ่อมแซม เปลี่ยนหน้าที่ |
| อำนาจภายใน | ข้อร้องเรียน ความเป็นธรรม ฐานสนับสนุน ตรวจสอบ ลงมติ ชิงอำนาจ สละตำแหน่ง |
| การเมืองระหว่างสำนัก | ทูต พันธมิตร การค้า ปิดการค้า สายสืบ บรรณาการ สงครามและสงบศึก |
| การต่อสู้และพื้นที่ | ประลอง รบ ส่งกำลัง ป้องกัน ยึดพื้นที่ เชลย หนี/ช่วย/ปล่อยเชลย ผลบาดเจ็บคงอยู่ |

การฝึกหมัด ฝ่ามือ ตัวเบา และอาวุธลับใช้ practiceTypes ที่ผูกกับวิชาจริง ไม่อาศัยชื่อชนิดอาวุธที่ไม่มีในฐานเดิม
โรงช่าง/โอสถช่วยแรงงานตามระดับ ความเสียหายลดกำลังผลิต ที่พักช่วยความพอใจ เรือนรักษาช่วยสุขภาพ
ประลองทั่วไปไม่สุ่มฆ่า แต่สงคราม/ประลองเป็นตายยังมีผลรุนแรงตามกฎ

## อำนาจ

ไม่พอใจสะสม → ยื่นข้อเรียกร้อง → กลุ่มสนับสนุน → ท้าทายผู้นำ → ตรวจสอบ/ลงมติ/ปฏิเสธ → เปลี่ยนผู้นำหรือความขัดแย้ง
ต้องมีผู้ท้าชิงที่มีสิทธิ์ ความชอบธรรมต่ำ ความตึงเครียด และเสียงสนับสนุนครบ ชิงอำนาจด้วยกำลังต้องมีเงื่อนไขเพิ่มและเกิดบาดเจ็บจริง ใช้กับสำนักผู้เล่นและสำนักภายนอก
มีปุ่มตอบข้อร้องเรียนและวิกฤตในหน้าสภาและเหตุการณ์เดิมของเกม

## ข้อมูลฝึกและเซฟ

เก็บสถานการณ์ก่อนตัดสินใจ รหัสกิจกรรมและเส้นทางตัวดำเนินการ พารามิเตอร์ ทางเลือกที่ตรวจแล้ว ผลทันที และผล 30/90/180 วัน รวมสุขภาพและกำลังของคนในสำนัก
ปิดค่าเริ่มต้น สุ่มทุก 20 การตัดสินใจ เพดาน 128 pending / 256 complete และ 12 ทางเลือกต่อรายการ
ไม่ใช้โมเดลภาษา ไม่มีเครือข่าย ไม่มีการฝึกออนไลน์ และยังไม่ได้เชื่อมโมเดลเก่าทั้งสองตัว
ตัดสำเนาสมองซ้ำที่อยู่ในภาพย้อนหลังของสำนักออก ไม่ลบสมองหรือความทรงจำของคนที่ยังมีตัวตน
นำเข้าเซฟ schema 1–7 ผ่านตัวแปลงเดิมและ schema 7→8 เพิ่มการตรวจโครงสร้างใหม่ก่อนใช้เซฟ ป้องกันข้อมูลผิดรูปแบบทำให้เกมปัจจุบันถูกแทนที่

## ขอบเขต

ประชากรทั่วไปบางส่วนยังคำนวณเป็นยอดรวม ครอบครัวใหม่เป็นความสัมพันธ์คู่ครองและการดูแล ไม่ได้เพิ่มระบบสืบตระกูลเต็มรูปแบบ การย้ายสำนักใช้ฝ่ายที่มีอยู่ ไม่มีการสร้างสำนักอิสระใหม่
กิจกรรมอาชญากรรมต้องมีเงื่อนไขและมีหลักฐาน/ความสัมพันธ์ตามมา แต่ยังไม่ใช่ระบบคดีพร้อมพยานและการพิจารณาคดีหลายชั้นแบบเกมกฎหมาย
การเจรจา/สอดแนมบางแบบใช้ผลระดับองค์กร กำลังรบใหญ่จำลองจากตัวแทนและกองกำลังเดิม ไม่แสดงกองทหารทุกคนเป็นบุคคล
