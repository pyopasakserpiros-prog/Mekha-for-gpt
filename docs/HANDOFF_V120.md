# MeKha 1.2.0 current handoff

Continue on MeKha's engine, never load SMK engine modules into this world. Canonical content stays at 662 items, 114 arts, 60 stories and 24 legends. patch-parity.js adapts SMK management/discovery/life concepts to MeKha's actual costs, rank and path-specific realm counts (6/7/5). Original HANDOFF_PATCH.md documents inherited code only.

Schema3 migrates schema2 using N.init without RNG, uid, item/resource/job/owner mutations. Schema1 first uses the existing migration. Storage prefix mekha_patch remains unchanged. Keep lastAllocationRevision/day counters and monthly summaries when changing schema. Current schema validates new nested structures before base validation can fill defaults. tests/fixtures/mekha-schema2.json is an actual owned weapon save.

New modules, loaded after inherited validation and before UI:
- patch-parity.js: policies, suitability scores, daily value budget, received-item revision, one automatic pill per person/day, leadership profile, weekly tasks, daily job assignment, community requests, independent regional item/material/recipe/art rolls, mount seats, quality crafting, member monthly lives and foreign spending/news.
- parity-validation.js: validates new fields and wraps N.validatePatch and G.validate.
- parity-ui.js after patch-ui: categorized paginated editor, quantity/quality/affix controls, allocation screen, equipment picker, members/foreign lives, community view and expedition pool information.
- patch-items.js delivers affixes; workOrders calls N.craftFinish and retains paid orders when the inventory cannot accept output.
- sim.js automatic promotions skip locked members. Body stress recovery is added for actual resting people, because base cultivation recovery runs only on cultivation jobs.

Daily outer order: initialize, community routine (once per date), weekly stewardship, automatic job plan, poison/body-rest recovery, inherited MeKha day (production, construction, crafting, cultivation, expeditions, faith, health, social/world/threats/events), inherited arts/stories -> replaced foreign/life routines -> weekly steward guard, then community aid, safe story delegation and item processing. All time uses G.stepDay. No real-time/offline idle simulation; asynchronous advance continues to stop on user-configured critical signals and unresolved decisions.

Allocation: N.addItem increments itemsRevision. Received items enter processing from editor/buy commands and at completed simulated days. N.allocate(automatic) permits a second same-day pass only for new inventory revision, preserving value spent in allocationBudgetDay. Manual re-distribution does not bypass the daily limit. Equipment uses role/path/art/weapon trait weights; owned locked gear cannot be replaced automatically. No owned gear transfer in automatic allocation. Pill effects ordered by health/toxicity/fatigue/mana then permitted development effects; actual N.usePill enforces cooldown and toxicity. A person receives at most one automatic pill/day even if more items arrive. itemReserve is per free stack (same definition/quality/affix/lock). Materials below grade3 are refined only under actual resource shortage, while preserving ingredients sufficient for one known recipe. Inventory merging remains inherited.

Initial new-game policies: maxGrade5, itemReserve0, daily value10000, boosts allowed, delegated safe stories. Old-save values remain unchanged. UI has explicit recommended-allocation adoption. Jobs set automatically for new leaders after succession only if delegation is enabled and the new leader is not locked; imported/direct locked jobs remain protected.

Community supplyRequest is separate from base v.need (faith calamities). Real food or unlocked healing-pill stacks are transferred; automation preserves foodDays, grade and itemReserve. Pending actions use existing G.pend/runAct. Only alerts for fulfilled requests are removed. Never suppress unrelated death/critical signals.

Foreign people remain the existing roster, part of faction military; do not create a second roster or add free troops. Named training spends real f.wealth/f.stock, rests body stress, has finite faith and real breakthrough preparation. Existing faction investment can also promote a person and is observed as paid advancement. ForeignInit/succession reuse existing live identity; serial ids are never recycled. News is deep copied on a schedule (90 public/30 close), or after paid scouting. View/filter rendering never consumes RNG or refreshes hidden live news. Archive/journal/month/history collections are capped. Base military rules remain inherited, so this is not numerically identical to SMK's 8-person observation subset.

Checks: python tools/regress.py; node tests/patch-longrun.js; python tools/package.py. Regression includes all 630 paid recipes, all 114 arts, all 60 story safe routes, resource transfer, editor coverage of every definition and real delegated UI handlers, save continuity and adversarial import rejection. The UI tests use DOM doubles and the actual inline entry; they do not prove real Android layout or file-manager behavior. No installed browser binary was available.
