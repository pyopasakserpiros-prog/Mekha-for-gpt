# เมฆา 1.2.0

แพทช์นี้นำพฤติกรรมและรายละเอียดของ SMK ที่ผู้เล่นเลือกมาปรับเข้ากับเกมเมฆา ไม่เปลี่ยนเมฆาเป็น SMK ทั้งเอนจิน และไม่เพิ่มไอเทมจาก 662 ชนิดเดิม

Edit เลือกหมวดก่อนเสก แยกอาวุธ เกราะ เครื่องประดับ พาหนะ โอสถ วัตถุดิบ รองเท้าและเครื่องมือ อาวุธมีตัวเลือกกระบี่/ดาบ/ทวน/ธนู/พัด/สนับหมัด/คทา/มีดสั้น กรองระดับและชุด ค้นชื่อ เปลี่ยนหน้า และเลือกจำนวน/คุณภาพ/คุณสมบัติพิเศษได้ ไม่มีการตัดให้เห็นแค่ 80 ชนิด

ผู้บริหารเลือกอุปกรณ์ตามหน้าที่และวิชาที่ใช้ ไม่ใช้แค่ผลรวมโบนัส ใช้โอสถตามความจำเป็นก่อนแล้วค่อยพัฒนา ตรวจขอบเขต มรรคา พิษยา ช่วงเว้นยา และผลซ้ำ การแจกอุปกรณ์และใช้โอสถมีหลักฐานในบันทึกแต่ละคน โควตาแจกเป็นมูลค่าต่อวัน ไม่มีการจ่ายเงินซ้ำสำหรับของในคลัง

หลังผลิต/สำรวจในวันนั้น ของเข้าระบบจัดสรรที่จบวัน หลังซื้อหรือเสกผ่านหน้า Edit จะประมวลผลทันที หากเกินเกณฑ์หรือใช้ไม่ได้ของยังอยู่ในคลัง วัตถุดิบใช้ผลิตหรือแปรตามการขาดแคลน ไม่ใช่ของสำหรับสวมให้คน

การบริหารภาพใหญ่มีเป้าหมายคน เงิน/เสบียงสำรอง การก่อสร้าง การเรียน การเลือกคัมภีร์ การผลิตของที่ขาดและการทูต บุคลิกเจ้าสำนักส่งผลต่อการเลือกและความสัมพันธ์ เช่นผู้ลำเอียงให้ผู้ใกล้ชิดก่อน ผู้รอบคอบกันเงินเผื่อ ผู้ทะเยอทะยานเพิ่มน้ำหนักพรสวรรค์ ผู้มีความสามารถด้านจัดการ/ถ่ายทอดเพิ่มแรงงานและการเรียน หัวหน้าฝ่ายโอสถ/หลอมช่วยคุณภาพการผลิต

ชุมชนขออาหารและโอสถจริงแยกจากภัยพิบัติที่ใช้ศรัทธา มีการส่งของ ปฏิเสธ เส้นตายและประวัติผล ถ้าตั้งช่วยอัตโนมัติจะไม่กินเสบียงสำรองหรือของล็อก

ชีวิตสมาชิกมีเหตุผลงาน ประวัติจากเหตุการณ์จริง เป้าหมายที่ต่อเนื่องเมื่อสำเร็จ และสรุปรายเดือน คนภายนอกใช้ทุนและเสบียงฝ่ายตัวเอง ฝึก พัก เลือกอาจารย์ สะสมศรัทธาและสืบทอดตำแหน่ง ข่าวแสดงตามวันที่ได้รับล่าสุด โลกไม่ได้หยุดเมื่อผู้เล่นเปิดหน้าอื่น

สำรวจแยกชุดตามธีมพื้นที่ 8 แห่ง ตามข้อมูล SMK มีชุดไอเทม วัตถุดิบ สูตรและตำรับแยกกัน ชนะได้วัตถุดิบประจำภูมิภาคแน่นอน การสุ่มอุปกรณ์มีคุณภาพและคุณสมบัติเสริม พาหนะหลายที่นั่งใช้ร่วมคณะได้

แก้ปัญหาผู้ถูกสั่งพักมีความเครียดกายาค้าง และเจ้าสำนักรุ่นใหม่ถูกล็อกให้สอนจนไม่ช่วยงานแม้เหลือคนเดียว การฟื้นและงานผู้บริหารใช้กฎเมฆาเดิมและทรัพยากรจริง

เกมใหม่เปิดช่วยบริหารและแจกของไว้แล้ว เซฟเดิมรักษานโยบายเดิม ให้กดมอบงานและใช้เกณฑ์แจกแนะนำหากต้องการเปิดทั้งหมด โลกจำลองเมื่อเดินเวลาเท่านั้น และยังหยุดตามเหตุสำคัญ/คำถามที่ผู้เล่นกำหนด
