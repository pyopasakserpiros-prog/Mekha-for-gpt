# ผลตรวจ MeKha 2.1.0

## ระบบและกิจกรรม

- ชุดตรวจรวม 22 สคริปต์ผ่าน ครอบคลุมกฎเดิม เนื้อหา คลัง วิชา ศิษย์–อาจารย์ โลก UI เซฟ และการย้ายรุ่น
- ชุดเฉพาะแพทใหม่ล่าสุด 27 สถานการณ์ผ่าน รวมเงินกู้/หนี้เลยกำหนด ผลิต/เรียนหลังใช้เวลา เงินค้ำขบวนค้า ข้อร้องเรียน ลงมติ ชิงอำนาจ ครอบครัว เชลย และการคืนทรัพย์เมื่อฝ่ายล่ม
- ตรวจทะเบียนเดิมครบ 220 รายการ ทะเบียนใหม่ 236 รายการมีระบบรองรับ
- Prepared action audit ผ่านครบ 212/212 ตัวดำเนินการตามเงื่อนไข ทดสอบโดยเตรียมสถานะที่ถูกกฎ ไม่ใช่บังคับให้ NPC ทำทุกอย่างในเกมปกติ และไม่ใช่หลักฐานว่าทุกกลไกมีความลึกเท่ากัน
- ตรวจปุ่มและหน้าจอใหม่ 42 การแสดงผลผ่านด้วย DOM stub รวมการแก้ข้อร้องเรียน เปิด/ปิดข้อมูลฝึก และส่งออก JSON
- เปิด index.html รวมไฟล์จริง กดเมนู เดินเวลา เซฟ/โหลด ผ่านทั้งกรณีพื้นที่เก็บข้อมูลใช้ได้และถูกบล็อก
- ใช้เซฟจากเอนจิ้น 2.0.0 จริง ตรวจว่าเงิน ไอเทม ID วัน และ RNG ไม่เปลี่ยนระหว่างย้ายเป็น schema 8
- ข้อมูลเสียหายถูกปฏิเสธโดยเซฟที่กำลังเล่นไม่เปลี่ยน บันทึกแล้วโหลดต่อให้ผลตรงกับการเล่นต่อเนื่อง

การมี 212 ตัวดำเนินการไม่ได้แปลว่าทั้งหมดปรากฏบ่อยในโลกธรรมชาติ การเมืองรุนแรงต้องมีเงื่อนไขเฉพาะ จึงตรวจเพิ่มด้วยสถานการณ์วิกฤตที่เตรียมไว้
เซฟอัตโนมัติและสำรองใช้พื้นที่รวมกัน หากเก็บหลายช่องหรือโลกใหญ่กว่านี้อาจเต็ม ต้องส่งออกเซฟเป็นไฟล์ ขนาดที่รายงานไม่ใช่การรับประกันพื้นที่ว่างบนโทรศัพท์

## ข้อจำกัดการตรวจ

ไม่ได้ทดสอบในเบราว์เซอร์จริงหรือบนโทรศัพท์ Android เครื่องจริง เครื่องทดสอบไม่มี Chromium และดาวน์โหลดติดนโยบายเครือข่าย 403
ผล UI จึงเป็น DOM stub ไม่ใช่ภาพจริง ไม่ใช่ benchmark Snapdragon 8 Elite และไม่ยืนยันการดาวน์โหลดจากทุกแอปเปิดไฟล์บน Android
มีสคริปต์ tests/civil-browser.js สำหรับตรวจ Chromium เมื่อมีสภาพแวดล้อมพร้อม รายงาน blocked อยู่ใน results-v210-browser.json

ยังไม่มีการฝึกโมเดลใหม่ ไม่มีการประเมิน AI Ranker/SectWorld Brain เทียบกฎเดิมในแพทนี้ ข้อมูล observational ยังต้องใช้คู่กับ counterfactual rollouts และโลกทดสอบที่แยกจากโลกฝึก
