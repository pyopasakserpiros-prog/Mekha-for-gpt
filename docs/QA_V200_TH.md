# รายงานตรวจสอบ MeKha 2.0.0

ฐานเกมคือ 1.4.0 ทางการจากงานก่อนหน้า ไม่ใช่การสร้างเกมใหม่ เซฟปัจจุบันใช้ schema 7

## การทดสอบระบบ

`python3 tools/regress.py` ผ่านทั้ง 19 ชุด ครอบคลุมระบบเดิม ไอเทม/วิชา ศิษย์–อาจารย์ การเรียน งานผลิต เวลา การย้ายเซฟ การบีบอัด และระบบโลกจำลองใหม่ รายละเอียดอยู่ใน `tests/results-v200-core.txt`

- โลกจำลองใหม่: 20 กลุ่มทดสอบ รวมเป้าหมายที่คืบหน้าจากผลจริง ข่าวที่ตัวละครไม่รู้ การแก้ข่าวผิด การถ่ายเงิน ความริษยา การประลอง การเดินทาง และโหลดต่อแบบรักษาสถานะสุ่ม
- การเชื่อมระบบ: 8 กลุ่ม รวมเงินบริจาคตรงจำนวน การสืบทอด เสบียงพ่อค้า การยึดพื้นที่ และการซื้อด้วยเงินตัวเองที่ไม่สร้างหนี้บุญคุณเทียม
- หน้าจอโลก: 42 มุมมองและปุ่มระดับความละเอียด/ตรวจการตัดสินใจ ผ่านด้วย DOM จำลอง
- เซฟ 1.4.0 ที่สร้างจากเอนจิ้นรุ่นเดิมจริงนำเข้าและดำเนินโลกต่อถึงวันที่ 215 ได้
- HTML รวมไฟล์ผ่านการเปิดเกม กดปุ่ม ข้ามเวลา และเซฟ ทั้งกรณีพื้นที่เก็บข้อมูลใช้ได้และถูกบล็อก
- ไฟล์ JavaScript ใน js/tests/tools ผ่านการตรวจไวยากรณ์ด้วย `node --check`

กรณีทดสอบเสริมที่ต้องใช้ bundle 1.2 ถูกข้ามเพราะไม่มีไฟล์นั้นในสภาพแวดล้อมนี้ ไม่ได้หมายความว่าทดสอบทุกเซฟเก่าที่เป็นไปได้แล้ว เซฟตัวอย่างจริงของ 1.3, Grok และ 1.4.0 ทางการมีการทดสอบนำเข้า

## การทดสอบระยะยาว

สคริปต์ `python3 tools/stress_v200.py` ใช้หก seed แยกโลก และจำลองโลกละ 3,600 วัน โดยปีในเกมคิดที่ 360 วัน มีจุดตรวจเดือนแรก หกเดือน หนึ่งปี และต่อเนื่องหลายปี

สถานการณ์ทดสอบใส่ทุนหนึ่งล้านเหรียญ เสบียงและของจำนวนมาก เปลี่ยนแนวบริหาร เปิดภารกิจและการทูต เพิ่มทุนฝ่ายภายนอก และเข้าสงคราม ตรวจทรัพยากรไม่ติดลบ เงินเก็บมีค่าจำกัด ขอบเขตความทรงจำ/ข่าว/สัมพันธ์ ประวัติรายเดือน เซฟที่ตรวจสอบได้ และการบีบอัดที่ถอดคืนตรงต้นฉบับ

ผลรายโลกอยู่ใน `tests/results-v200-stress-<seed>.json` และผลรวมใน `tests/results-v200-stress.json` ประวัติผล v130/v140 ที่เก็บไว้เป็นข้อมูลรุ่นเก่า ไม่ใช่หลักฐานผลรุ่นนี้

รอบส่งมอบผ่านครบหกโลก รวม 21,600 วัน ทุกโลกถึงวันที่ 3,600 โดยไม่จบเกมก่อนกำหนด:

| --- | ---: | ---: | ---: |

| 17 | 3,600 | 9.02 | 2.13 |

| 233 | 3,600 | 9.21 | 2.15 |

MB ในตารางเท่ากับ 1,000,000 ไบต์ เซฟส่งออกวัด UTF-8 ส่วนพื้นที่เก็บในเบราว์เซอร์ประมาณจากสองไบต์ต่อ UTF-16 code unit ไม่รวมค่าใช้จ่ายอื่นของเบราว์เซอร์

รายงานเดือนแรกของแต่ละโลกติดตาม 17 คน ทั้ง 17 คนมีกิจกรรมที่บันทึกอย่างน้อยห้าครั้ง ไม่ได้หมายความว่าทุกคนทุกระดับจำลองมีจำนวนเท่ากัน รอบทดสอบรวมมีการประเมินตัดสินใจ 2,145,999 ครั้งและทางเลือก 92,367,862 รายการ ความทรงจำสูงสุด 48 และข่าวที่รู้สูงสุด 32 รายการต่อคน

เวลา tick P95 รายโลกอยู่ช่วง 89.41–99.39 มิลลิวินาทีบนเครื่องทดสอบ ไม่รวมการเซฟ/ตรวจเซฟที่จุดตรวจ และไม่ใช่ผลวัดมือถือ

## ขอบเขตของผลทดสอบ

ผลนี้เป็นเอนจิ้น Node และหน้าจอจำลอง ไม่ได้เปิดด้วย Chrome จริงหรือทดสอบบน Android/Snapdragon 8 Elite เวลาแต่ละ tick ในรายงานเป็นเวลาบนเครื่องทดสอบ ขณะที่มีสามโลกทำงานพร้อมกัน ไม่ใช่ตัวเลขความเร็วมือถือ

เกมคืนการควบคุมหน้าจอระหว่างวัน แต่การคำนวณหนึ่งวันยังเป็นงาน synchronous ไม่มี Web Worker และไม่มีการรับประกันเฟรมไทม์บนมือถือ

การผ่านหก seed ไม่พิสูจน์ว่าไม่มีบั๊กในทุกสถานการณ์ หรือว่าความสมดุลสงคราม/เศรษฐกิจเหมาะสมทุกโลก โดยเฉพาะการทดสอบนี้เติมทรัพยากรเพื่อกดดันระบบ ไม่ใช่หลักฐานว่าสำนักเริ่มต้นทุกแห่งอยู่รอดสิบปีโดยไม่ช่วยเหลือ

แนะนำส่งออกเซฟก่อนย้ายรุ่นและเป็นระยะ เซฟหลายช่องหรือเปิดโหมดตรวจสอบยาวนานยังอาจใช้พื้นที่เบราว์เซอร์จนเต็มได้
