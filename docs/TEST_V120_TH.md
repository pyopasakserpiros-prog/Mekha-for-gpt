# รายงานทดสอบเมฆา 1.2.0

ตรวจจากโค้ดและไฟล์เล่นจริงในสภาพแวดล้อม Linux / Node.js v24.19.0 ไม่ใช่โทรศัพท์ผู้เล่น

ผ่านกลุ่มตรวจเอนจินเดิม 26 กลุ่ม ส่วนเสริมเดิม 19 กลุ่ม และพฤติกรรมแพทช์ใหม่ 17 กลุ่ม รวม 62 กลุ่ม
หน้า UI ส่วนเสริมตรวจ 1,472 การเรนเดอร์ พร้อมตัวจัดการคำสั่งจริง; หน้าหมวด Edit และระบบใหม่ตรวจอีก 81 การเรนเดอร์
ตรวจทุกหน้าจอเมื่อเดินเวลา 400 วัน และทดสอบ index.html ที่รวมสคริปต์จริงทั้งกรณีเก็บเซฟได้และกรณีเบราว์เซอร์บล็อกการเก็บเซฟ

รายละเอียดที่ผ่าน
- ครบ 662 ไอเทม 114 วิชา 60 เรื่อง 24 ผู้เดินทาง; สูตรผลิตทั้ง 630 ชนิดผ่านการจ่ายวัสดุ ลงแรงและรับของ
- เดินทุกหมวดและทุกหน้าของ Edit เข้าถึงครบ 662 ชนิด; เสกหลายชิ้น คุณภาพและคุณสมบัติได้; เสกแล้วเข้าระบบแจกจริง
- อุปกรณ์เลือกตามงาน/มรรคา/วิชา พิษยาและช่วงเว้นยา ของล็อก ข้อยกเว้น สำรองกอง และมูลค่ารวมต่อวันผ่าน
- ของสำรวจถึงสำนักแล้วคงคุณภาพ/คุณสมบัติพิเศษ สูตรได้จริง และเข้าแจกในวันกลับ
- คำขออาหาร/โอสถหักคลังจริง และไม่ใช้ของล็อกหรือกินสำรองเมื่อช่วยอัตโนมัติ
- สำรวจ 8 พื้นที่ รวม 400 ครั้งที่จัดเงื่อนไขชนะ ตรวจว่าได้วัตถุดิบแน่นอนและไอเทมตรงธีม
- ข่าวต่างสำนักเป็นภาพ ณ วันที่ได้รับ ไม่อัปเดตสถานะลับสดและไม่กิน RNG เมื่อเปิดหน้าดู
- เซฟ schema1 และเซฟ schema2 ที่มีของสวมอยู่ ย้ายได้โดยไม่เพิ่มทรัพยากรหรือเปลี่ยน RNG/งาน/เจ้าของ
- ปฏิเสธข้อมูลนโยบาย ชีวิตบุคคล ข่าวและของสำรวจที่เสียหายก่อนทับเกมปัจจุบัน
- บันทึก/โหลดระหว่างเรียน เรื่องต่อเนื่องและคิวผลิตให้ผลต่อเนื่องเท่ากัน เดินหลายวันตรงกับเดินวันเดียว
- ผู้พักฟื้นความเครียดกายาลดจริง เจ้าสำนักรุ่นใหม่เมื่อมอบอำนาจแล้วไม่ถูกล็อกไว้สอนจนไม่ช่วยงาน
