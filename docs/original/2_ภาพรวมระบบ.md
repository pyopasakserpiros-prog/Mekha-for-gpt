# ภาพรวมระบบ (สำหรับผู้เล่น)

**เวลา:** 1 ปี = 360 วัน (4 ฤดู ฤดูละ 90 วัน เดือนละ 30 วัน) การจำลองเป็นรายวัน ลำดับในแต่ละวัน: สภาพแวดล้อม → การสอน → ผลผลิต → ก่อสร้าง → ปรุง/หลอม → บริโภค → บำเพ็ญ → คณะสำรวจ → ศรัทธา → สุขภาพ → สังคม → โลกภายนอก → ภัยคุกคาม → เหตุสุ่ม → งานรายเดือน/มอบหมายงาน (เดิน N วัน = เดินทีละวัน N ครั้ง ผลเหมือนกัน และทดสอบแล้ว)

**ศิษย์:** มีพรสวรรค์ 3 สาย คุณลักษณะ ความภักดี ความพอใจ สุขภาพ บาดเจ็บ เป้าหมาย ความสัมพันธ์ อาจารย์ ประวัติ ความพอใจอธิบายเหตุได้ (แตะ "เหตุที่ทำให้พอใจ/ไม่พอใจ") ผู้ที่ไม่พอใจมากอาจออกจากสำนัก

**เส้นทางบำเพ็ญ:** ปราณ 6 ขั้น · กายา 7 ขั้น · ศรัทธา 5 ขั้น แต่ละสายมีคัมภีร์ 4 เล่ม (เริ่มต้นรู้ 1 เล่มต่อสาย อีก 3 เล่มต้องค้นพบจากการสำรวจ) การทะลวงขั้นมีเงื่อนไข ทรัพยากร โอกาสสำเร็จที่อธิบายปัจจัยได้ และผลล้มเหลวหลายระดับ การเปลี่ยนคัมภีร์/สายมีค่าใช้จ่ายและเสียความก้าวหน้า

**ระบบศรัทธา:** ศิษย์สายศรัทธาดูแลชุมชน (หมู่บ้าน 4 แห่ง) ความเชื่อมั่นและความศรัทธาของชุมชนเปลี่ยนตามการดูแล ความสนใจมีจำกัด (ดูแลหลายที่ ได้น้อยลง) ชุมชนมีความต้องการเร่งด่วน (สัตว์ร้าย โรค ภัยธรรมชาติ สงคราม) ที่ใช้ศรัทธาแก้ได้ภายในเวลา มีคำสาบาน คู่แข่งทางศรัทธา และศรัทธาสำรองที่ตั้งได้

**เศรษฐกิจ:** เสบียง เงิน สมุนไพร แร่ ไม้ วัตถุดิบอสูร หินวิญญาณ ยา 4 ชนิด อาวุธ/เกราะ อาคาร 11 ชนิด (ระดับ) ตลาดซื้อขาย (ราคาขยับตามปริมาณ) ข้อตกลงการค้ากับฝ่ายอื่น

**ฝ่ายอื่น 6 ฝ่าย:** นิสัย (ก้าวร้าว โลภ ถือเกียรติ) ความสัมพันธ์ ความไว้วางใจ ต่างกัน ข้อมูลที่เรามีเกี่ยวกับพวกเขาเป็น "การประเมิน" ที่อาจเก่า/คลาดเคลื่อน และโจรก็ประเมินเราจากข้อมูลที่เก่าได้เช่นกัน ฝ่ายที่ใกล้ชิดกับเรา (พันธมิตร สงคราม มีข้อตกลงค้า) จะถูกจำลองละเอียดขึ้น (มีรายชื่อบุคคล) โดยจำนวนคนและกำลังรวมคงเดิม ล็อก 60 วันก่อนกลับสู่ระดับหยาบ

**การรบ:** อัตโนมัติเป็นรอบ ตั้งยุทธวิธี (รุก/สมดุล/ตั้งรับ) และจุดถอยได้ ระดมศิษย์เพิ่มเมื่อผู้เฝ้ายามไม่พอ ทุกศึกมีบันทึกเหตุผลและรายละเอียดรอบ

**คณะสำรวจ:** 6 สถานที่ (2 แห่งเป็นข่าวลือที่ต้องค้นพบก่อน) ได้ทรัพยากร เบาะแสคัมภีร์ ข่าวสาร มีความเสี่ยงบาดเจ็บ/ตาย

**ผู้สืบทอด:** เมื่อเจ้าสำนักสิ้นชีพ คุณเลือกผู้สืบทอดจากผู้สมัครสูงสุด 4 คน ผู้ทะเยอทะยานที่ไม่ได้รับเลือกเสียความภักดี

**ข้อจำกัดของเวอร์ชันนี้ (ซื่อตรง):** ไม่มีการฝึกสองสายพร้อมกัน · ไม่มี Web Worker (จำลองบนเธรดหลักแบบแบ่งก้อน) · เศรษฐกิจเงินค่อนข้างนิ่ง (เงินคงที่ราว 200–300 ในการทดสอบอัตโนมัติ) · ฝ่ายป้องกันมักแพ้การบุกของโจรหากผู้เล่นไม่ลงทุนกำแพง/ยามเพิ่ม (ในทดสอบอัตโนมัติ แพ้มากกว่าชนะ แต่สำนักยังอยู่รอดทุกเมล็ดสุ่ม)
