# แก้ไขการเปิดเกม v1.0.1

ไฟล์เดิม index.html มีเพียง 813 ไบต์และโหลด JavaScript เจ็ดไฟล์กับ CSS หนึ่งไฟล์จากโฟลเดอร์ข้างเคียง หากเปิด HTML เดี่ยว ๆ หรือแอปเปิดไฟล์ส่งต่อเฉพาะไฟล์นั้น ส่วนเกมจะไม่ถูกโหลดและหน้าจอเดิมไม่มีข้อความอธิบาย ทั้งนี้ยังไม่ได้ยืนยันสาเหตุบนเครื่องของผู้ใช้

ฉบับแก้ไขรวมทรัพยากรทั้งหมดไว้ใน index.html ไม่มีคำขอเครือข่าย ไม่ต้องติดตั้งเครื่องมือ และเพิ่มข้อความเริ่มต้น/กรณี JavaScript ปิด/เริ่มเกมผิดพลาด ยังคงฐานข้อมูล กลไก และรูปแบบเซฟเดิม เปลี่ยนเวอร์ชันเป็น 1.0.1

การตรวจสอบใหม่ใช้สคริปต์จริงจาก HTML ที่รวมแล้ว ทดสอบการเริ่มเกม กดทุกแท็บ เดินเวลา ส่งออกและนำเข้าเซฟ รวมถึงพื้นที่บันทึกที่ถูกบล็อก ด้วย DOM จำลองใน Node และรันชุดทดสอบเดิมเพิ่มเติม ไม่มีการทดสอบบน Chrome หรือ Android จริงในครั้งนี้เพราะติดตั้งเบราว์เซอร์ในสภาพแวดล้อมทดสอบไม่ได้ รายงานทดสอบ v1.0.0 ที่อยู่ในไฟล์เป็นรายงานจากผู้พัฒนาเดิม
